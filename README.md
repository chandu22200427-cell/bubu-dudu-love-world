Bubu & Dudu — Our Little Love World

Files:
- index.html: page structure and nine scenes
- style.css: responsive pastel design and animations
- script.js: slide navigation, activities, message interactions and floating petals
- assets/: artwork files

Run locally:
1. Open this folder in VS Code.
2. Open index.html and use Live Server, or open index.html directly in Chrome.
3. GitHub Pages can host this static HTML/CSS/JS project.

Artwork note:
The character PNGs are preliminary crops from a combined artwork sheet and may include backgrounds or borders. Replace/clean those files later for the best visual result.
The Google Fonts import requires internet; fallback fonts are included.
No music track is included, so the music control reports that no track has been added.
